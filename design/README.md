
## What the activity journal measures

The journal covers the last 365 **completed UTC days**, with the last 30 days shown as daily bars:

- **Contributions**: counts from the publicly visible contribution calendar. This is not a commit count; GitHub counts other contribution types and may expose anonymous private contribution totals according to the account’s settings.
- **Public commits**: GitHub’s indexed commit-search count for `author:sakarkhadka10` and the selected author-date range. It excludes inaccessible private repositories and is subject to GitHub’s search indexing.
- **Longest streak**: consecutive days with at least one calendar contribution inside the displayed window.
- **Public repo stars**: current stars across the account’s public, non-fork repositories.
- **Active days**: calendar days with at least one contribution. Public repository count excludes forks.

`assets/activity.json` holds the normalized source snapshot. Regenerate its SVGs offline with the command above. To collect fresh data, set `GH_TOKEN` and run `python .github/scripts/refresh-activity.py` without `--snapshot`.

The initial journal uses GitHub REST metadata and commit search, plus the public contribution calendar from [github-contributions-api](https://github-contributions-api.jogruber.de/v4/sakarkhadka10), through November 11, 2026. No missing dates are invented. The scheduled workflow uses GitHub’s official GraphQL contribution calendar and REST APIs. It rejects incomplete commit searches and calendar gaps before replacing published files.

## Daily refresh and koi

`.github/workflows/profile-assets.yml` refreshes the journal, graphs, and [git-koi](https://github.com/yalongwastaken/git-koi/blob/v1.0.2/docs/getting-started.md) daily at **00:37 UTC / 06:22 Nepal time**. GitHub may delay scheduled jobs. The workflow also runs when its file or relevant generator sources change on `main`, or manually from **Actions → Notebook activity → Run workflow**.

The built-in `GITHUB_TOKEN` is sufficient; no personal access token or additional secret is required. The workflow commits only changed activity assets and the koi GIF. The third-party koi action is pinned to `v1.0.2`, with the blue-accented `asagi` body. Its release download checks the upstream SHA-256 checksum.

The included initial koi was generated with the checksum-verified official v1.0.2 binary using the account’s public owned repositories and complete publicly visible calendar history from account creation through November 11, 2026. The action subsequently replaces it with its own snapshot, including public contributed repositories.

If repository or branch policies prevent the built-in token from pushing, inspect the failed run and the repository’s Actions/branch settings. GitHub may pause scheduled workflows after 60 days of repository inactivity; re-enable the workflow from Actions if needed.
